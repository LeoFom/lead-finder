## Overture і версіонування

19.11.2026 прямим читанням STAC підтверджено `latest: 2026-11-18.0`, каталог цього релізу та схему `2.0.0`. Колекція Places має `license: other`, тому ліцензії внесків перевіряються окремо. Перед фактичним імпортом повторно перевірити реліз, його матеріали та зафіксувати ідентифікатор. Дата у календарному плані сама по собі не є свідченням публікації. [Каталог STAC](https://stac.overturemaps.org/catalog.json) · [Підтверджений реліз](https://stac.overturemaps.org/2026-11-18.0/catalog.json) · [Аналіз підключення джерел](DATA_COLLECTION_RESEARCH.md)

Схема Place містить `id`, геометрію, `names`, `sources[]`, `basic_category`, `taxonomy`, а також опційні сайти, соціальні URL, адреси, контакти й `operating_status`. Зіставлення слова «Стоматологія» має використовувати версіонований словник релізу з primary, hierarchy та alternates. Зміна цього словника змінює scope порівняння. Походження перевіряється за dataset і property, включно з кількома внесками. Для порожньої ліцензії джерела потрібна однозначна прив’язка до перевіреного реєстру відповідного релізу. Невизначені внески відкидаються. [Схема Place](https://docs.overturemaps.org/schema/reference/places/place/) · [Таксономія](https://docs.overturemaps.org/guides/places/taxonomy/) · [Версіоновані словники](https://docs.overturemaps.org/guides/places/taxonomy-explorer/)

У переліку Places наведено CDLA-Permissive-2.0 для низки постачальників, Apache-2.0 для внесків Foursquare та CC0-1.0 для AllThePlaces. Для дозволеної видачі зберегти належні тексти ліцензій, авторства, NOTICE й повідомлення про зміни відповідно до внеску. У файлі вказувати прив’язку поля до джерела і релізу. [Attribution and Licensing](https://docs.overturemaps.org/attribution/#places) · [Places Guide](https://docs.overturemaps.org/guides/places/)

## Інші джерела

Google обмежує скрейпінг, кешування й використання Maps Content для каталогів. Виняток для кешування place ID не дає нашому продукту права формувати CRM із Places. Дозволена у продукті дія користувача — відкрити зовнішній пошук за `api=1` з URL-encoded query і записати власний висновок. [Умови Google](https://cloud.google.com/maps-platform/terms) · [Політика Places](https://developers.google.com/maps/documentation/places/web-service/policies) · [Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)

Стандартні умови Brave від 01.09.2026 обмежують створення БД з видачі, її утримання і передачу. Сторінка API відсилає за правами зберігання до окремого плану. Дозвіл на один вид використання не розширює експорт автоматично. [Brave API Terms](https://api-dashboard.search.brave.com/app/documentation/general/terms-of-service) · [Brave API FAQ](https://brave.com/search/api/)

OSM потребує ODbL та атрибуції. Для регулярної обробки обирати відповідні регіональні витяги або власний сервіс. Для бізнес-сайтів robots.txt регулює поведінку crawler, право зберігати та експортувати оцінюється окремо. Публічність контакту також не встановлює згоди на маркетинг. Перед виходом на інший ринок оцінювати місцеві вимоги і забезпечувати opt-out. [OSM](https://www.openstreetmap.org/copyright) · [Nominatim](https://operations.osmfoundation.org/policies/nominatim/) · [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309) · [Приклад правил B2B для Великої Британії](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/business-to-business-marketing/)

## Межа технічного дозволу

Кожному значенню потрібні sourceType, sourceRef, field, license, dataset, observedAt, confidence, права на зберігання та експорт, attribution. Для Overture потрібен releaseId. Сервер звіряє їх із власним активним grant для цього джерела, набору, релізу й поля. Серед дозволів фази 0 є лише незалежні ручні спостереження. Зміна вхідного прапорця не активує зовнішній адаптер. [Реалізація](../packages/data-sources/src/index.ts)

Перед відправленням у чергу з payload, записом проєкції, diff або підготовкою файлу перевіряти всі внески. Перевірка прав не доводить істинність факту. У фазі 6 довірений адаптер реконструює походження за перевіреним релізом. У фазі 11 до XLSX додати лист «Джерела та ліцензії», до CSV — metadata-файл, включно з необхідними ліцензійними матеріалами. Строк дії та відкликання перевіряються також перед видачею раніше створеного файлу. [Рішення про ліцензії](adr/0001-source-rights.md)
